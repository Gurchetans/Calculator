# Calculator

This is a simple, user-friendly calculator web app created using HTML, CSS, and JavaScript. It allows users to perform basic arithmetic calculations like addition and subtraction with a clean and responsive interface.

## Features

- **Basic Arithmetic Operations**: Supports addition and subtraction.
- **Clear Functionality**: Includes a button to clear the input field.
- **Responsive Design**: The layout adjusts seamlessly to different screen sizes, ensuring a smooth experience across devices.
- **Interactive Buttons**: Buttons are styled with hover and active states for better user interaction.

## Technologies Used

- **HTML**: The structure of the calculator and form elements.
- **CSS**: Used for styling the layout, buttons, and display, as well as ensuring the calculator is centered and responsive.
- **JavaScript**: For the functionality of the calculator, enabling button clicks to update the display and calculate results.


## How to Use

1. Clone or download this repository to your local machine.
2. Open the `index.html` file in your browser.
3. Use the buttons to perform basic arithmetic calculations:
   - **Numbers**: Click the numeric buttons to enter values.
   - **Operators**: Click the "+" or "-" buttons for addition or subtraction.
   - **Equal (=)**: Press the "=" button to evaluate the result.
   - **Clear**: Click the "all clear" button to reset the input field.

## Functionality

- **Input Field**: Displays the numbers and operators as the user clicks the buttons.
- **Evaluate**: The `=` button evaluates the current input using JavaScript's `eval()` function to compute the result.
- **Clear**: The "all clear" button resets the input field to an empty state.
